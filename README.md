# 思无涯 (MindVoid)

> 一个预测输入的外挂界面，用于学习、实践、训练 AI。
> A predictive-input overlay interface for learning, practicing, and training AI.

## 简介 (Introduction)

**思无涯 (MindVoid)** 是一款预测输入的外挂界面工具。它不取代现有的输入法，而是在您打字时**平行运行**，实时预测后续输入，并支持**自训练**。

- **🔌 平行运行** — 不影响原有输入法功能，叠加工作
- **⚡ 实时预测** — 边打字边预测，即时反馈
- **🧠 自训练** — 根据您的输入习惯持续学习和优化
- **🎯 学习与实践** — 适合 AI 学习者、输入法爱好者、效率追求者

## 核心理念

| 概念         | 说明                                      |
| ------------ | ----------------------------------------- |
| **思无涯**   | 思维没有边界 — 工具辅助思考，而非限定输入 |
| **MindVoid** | 心智的空杯 — 保持开放，持续吸收与学习     |
| **外挂界面** | 不侵入输入法进程，作为独立层叠加          |
