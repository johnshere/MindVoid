## 1. 模型后端接口

```rust
/// 模型后端统一接口（定义在 mindvoid-core）
pub trait ModelBackend: Send + Sync {
    /// 推理：给定特征上下文，返回 Top-K 候选
    fn predict(&self, features: &FeatureVec) -> Vec<Prediction>;

    /// 增量训练：单条样本即时更新
    fn train_incremental(&mut self, sample: &TrainSample);

    /// 批量训练：多条样本全量更新
    fn train_batch(&mut self, samples: &[TrainSample]);

    /// 序列化到文件
    fn save(&self, path: &Path) -> Result<()>;

    /// 从文件加载
    fn load(path: &Path) -> Result<Self> where Self: Sized;

    /// 模型统计信息
    fn stats(&self) -> ModelStats;
}

pub struct Prediction {
    pub text: String,       // 候选词
    pub confidence: f32,    // 置信度 [0, 1]
}

pub struct TrainSample {
    pub context: String,    // 输入上下文（前 N-1 字）
    pub output: String,     // 用户实际输出
    pub confidence: Confidence,
}

pub enum Confidence { High, Low, ImplicitNegative }

pub struct ModelStats {
    pub total_ngrams: usize,
    pub unique_contexts: usize,
    pub total_samples_trained: u64,
}
```

## 2. 模型实现方案（研究课题）

> ⚠️ **重要：预测模型是本项目的核心学习研究课题。**
> 以下描述的是架构层面的概念和参考实现思路，**不作为最终方案**。
> 具体的数据结构选择、N 值确定、分词策略等需在后期实验和研究中确定。
> 模型层通过 `ModelBackend` trait 隔离实现细节，确保兜底方案与自研方案可互换。

### 2.1 参考方案：字级别 N-Gram

以下是**一种可行的兜底参考方案**，用于在自研模型不可用或冷启动时提供基础预测能力：

| 参数 | 参考设定 | 说明 |
|------|---------|------|
| N | 4（3 字上下文 → 1 字预测） | 可实验 2~5 的 N 值 |
| 数据结构 | `BTreeMap` / `HashMap` / `Trie` 等 | 可选方案，各有取舍 |
| 预测 | 基于历史计数 Top-K | 纯统计，无矩阵运算 |
| 更新 | 每次用户选择后即时调整计数 | 在线学习 |
| 冷启动 | 零样本 + 高频字 fallback | 可替换为预训练基座 |
| 序列化 | 待定格式 | 需考虑文件大小和加载速度 |

**为什么考虑 char-level？** 中文无天然词边界，character-level 免去分词依赖，实现简单。word-level 需要分词器前置，效果好但依赖分词准确率——这是值得实验的课题。

### 2.2 参考数据结构

```rust
use std::collections::BTreeMap;

pub struct CharNGramModel {
    n: usize,                                  // N 值 (4)
    data: BTreeMap<ContextKey, BTreeMap<char, u32>>,
    total_samples: u64,
}

/// 固定长度的上下文 key: N-1 个字符
type ContextKey = [char; 3];  // N=4 时, 前 3 字
```

**内存估算：**

| 规模 | 数据结构 | 估算 |
|------|---------|------|
| 1 万条样本 | BTreeMap | ~500 KB |
| 10 万条样本 | BTreeMap | ~3 MB |
| 100 万条样本 | BTreeMap | ~25 MB |
| 千万级 | 需考虑磁盘索引 | — |

**内存安全上限 < 50MB**（§8 KPI），对应的千万级 N-Gram 对个人用户足够。

### 2.3 参考推理流程

```rust
impl ModelBackend for CharNGramModel {
    fn predict(&self, features: &FeatureVec) -> Vec<Prediction> {
        // 1. 取上下文：前 N-1 个字符
        let context: Vec<char> = features.context_chars.iter()
            .rev().take(self.n - 1).rev().collect();

        if context.len() < self.n - 1 {
            return self.fallback_top5(); // 冷启动兜底
        }

        // 2. 构造 key
        let key: ContextKey = [context[0], context[1], context[2]];

        // 3. 查询
        if let Some(counts) = self.data.get(&key) {
            // 4. 按 count 降序，取 Top-5
            let mut sorted: Vec<_> = counts.iter().collect();
            sorted.sort_by(|a, b| b.1.cmp(a.1));
            let total: u32 = sorted.iter().map(|(_, c)| *c).sum();

            sorted.into_iter().take(5)
                .map(|(ch, count)| Prediction {
                    text: ch.to_string(),
                    confidence: *count as f32 / total as f32,
                })
                .collect()
        } else {
            self.fallback_top5() // 无匹配 → fallback
        }
    }
}
```

### 2.4 参考训练更新

```rust
impl CharNGramModel {
    fn train_incremental(&mut self, sample: &TrainSample) {
        // 1. 构造 (context → output) 对
        let context_chars: Vec<char> = sample.context.chars().collect();
        let output_chars: Vec<char> = sample.output.chars().collect();

        // 2. 滑动窗口生成 N-Gram
        for i in 0..context_chars.len().saturating_sub(self.n - 2) {
            if i + self.n - 1 < context_chars.len() {
                let key: ContextKey = [
                    context_chars[i],
                    context_chars[i + 1],
                    context_chars[i + 2],
                ];
                let next_char = context_chars[i + 3];
                *self.data.entry(key).or_default().entry(next_char).or_insert(0) += 1;
            }
        }

        // 3. 如果用户选了候选（而非继续打字），也训练 (context, selected)
        if !sample.output.is_empty() && sample.output != sample.context {
            let last_ctx: Vec<char> = context_chars.iter()
                .rev().take(self.n - 1).collect::<Vec<_>>()
                .into_iter().rev().collect();
            if last_ctx.len() == self.n - 1 {
                let key: ContextKey = [last_ctx[0], last_ctx[1], last_ctx[2]];
                for ch in output_chars {
                    *self.data.entry(key).or_default().entry(ch).or_insert(0) += 1;
                }
            }
        }

        self.total_samples += 1;
    }
}
```

## 3. 序列化方案（参考）

### 3.1 文件格式

```
文件头:
  magic:    [u8; 4] = b"NG4M"   (N-Gram 4-gram Model)
  version:  u32 = 1
  n:        u32 = 4             (N 值)
  entries:  u64                 (总 entry 数)
  checksum: u32                 (CRC32 of data section)

数据段 (重复 entries 次):
  prefix:   [u8; 3*4] = [char; 3] 编码为 UTF-32 LE
  num_next: u32                    (后续字数量)
    对于每个后续字:
      char:  [u8; 4]  (UTF-32 LE)
      count: u32
```

### 3.2 原子写入

```rust
impl CharNGramModel {
    pub fn save_atomic(&self, target_path: &Path) -> Result<()> {
        let tmp_path = target_path.with_extension("tmp");

        // 1. 写入临时文件
        let mut f = BufWriter::new(File::create(&tmp_path)?);
        self.write_binary(&mut f)?;
        f.flush()?;
        drop(f);

        // 2. fsync 保证落盘 (Windows 不需要 fsync, FlushFileBuffers 已足够)
        #[cfg(not(windows))]
        { File::open(&tmp_path)?.sync_all()?; }

        // 3. 原子 rename
        std::fs::rename(&tmp_path, target_path)?;

        Ok(())
    }
}
```

### 3.3 加载与校验

```rust
impl CharNGramModel {
    pub fn load_verified(path: &Path) -> Result<Self> {
        let data = std::fs::read(path)?;

        // 1. 校验 magic
        if &data[0..4] != b"NG4M" {
            return Err(Error::ModelCorrupted { path: path.to_owned() });
        }

        // 2. 校验 CRC32
        let stored_crc = u32::from_le_bytes(data[20..24].try_into().unwrap());
        let computed_crc = crc32fast::hash(&data[24..]);
        if stored_crc != computed_crc {
            return Err(Error::ModelCorrupted { path: path.to_owned() });
        }

        // 3. 反序列化
        Self::parse_binary(&data[24..])
    }
}
```

## 4. 训练流水线

### 4.1 双缓冲队列

```rust
use std::sync::{Arc, Mutex};

pub struct TrainingPipeline {
    hot_buffer: Arc<Mutex<Vec<TrainSample>>>,  // 热缓冲（内存，累积中）
    batch_size: usize,                         // 50
    model: Arc<ArcSwap<CharNGramModel>>,       // 原子替换
}

impl TrainingPipeline {
    /// 事件线程调用：追加样本（非阻塞，仅 push）
    pub fn push_sample(&self, sample: TrainSample) {
        let mut buf = self.hot_buffer.lock().unwrap();
        buf.push(sample);
        // 通知训练线程有新样本（通过 channel 或 Condvar）
    }

    /// 训练线程调用：批量取走并训练
    pub fn drain_and_train(&self) {
        let mut buf = self.hot_buffer.lock().unwrap();
        if buf.len() >= self.batch_size {
            let batch: Vec<_> = buf.drain(..).collect();
            drop(buf);
            self.train_batch(batch);
        }
    }

    /// 训练线程调用：批量更新模型
    fn train_batch(&self, samples: Vec<TrainSample>) {
        let current = self.model.load();  // 读当前模型 (Arc)
        let mut new_model = (*current).clone();

        for sample in &samples {
            new_model.train_incremental(sample);
        }

        // 原子替换：推理线程下次 predict 自动使用新模型
        self.model.store(Arc::new(new_model));
    }
}
```

**为什么 `ArcSwap`？**
- 推理线程 `predict()` 是纯读（高频），不能加锁
- 训练线程更新模型（低频），用 `store` 原子替换
- 推理线程拿到的是不可变快照，训练不阻塞推理

### 4.2 训练策略参数

| 策略 | 触发条件 | 操作 | 线程 |
|------|---------|------|------|
| 即时增量 | 每 50 条样本 | 批量更新 BTreeMap count | 训练线程 |
| 会话结束 | 程序关闭 | flush 热缓冲 + 原子写磁盘 | 主线程 |
| 全量重训 | 手动触发 (CLI) | 从头扫历史语料重建模型 | 后台线程 |

- "即时增量" 耗时 < 100ms（50 条 × BTreeMap 更新）
- 全量重训暂不实现（Phase 2），N-Gram 纯计数的"重训"等价于重新加载磁盘文件

```
├── models/
│   ├── current/

│   └── base/                 ← 初始基座（本方案为空，冷启动）
├── data/
│   ├── session_log.bin       ← 当前会话原始事件日志

│   └── user_profile.json     ← 用户习惯画像
└── config.toml
```

### SQLite 表结构

```sql
CREATE TABLE training_samples (
    id        INTEGER PRIMARY KEY AUTOINCREMENT,
    context   TEXT NOT NULL,
    output    TEXT NOT NULL,
    confidence TEXT NOT NULL,  -- 'high' | 'low' | 'implicit_negative'
    app_name  TEXT,
    created_at TEXT DEFAULT (datetime('now'))
);

CREATE INDEX idx_samples_context ON training_samples(context);
```
